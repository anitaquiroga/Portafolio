Image Generator

An automated creative workflow connecting Monday.com, Make and Gemini-powered image generation to streamline the creation and delivery of marketing assets.

01 — Overview

The project

The goal was to create an automated image-generation workflow for the marketing team. The system allowed marketers to submit an image-generation request directly from Monday.com, including a description and optional reference images, and receive the generated asset automatically within the same workflow.

🎨

AI Image Generation

Used Gemini-powered image generation through Nano Banana to create marketing assets based on structured prompts.

✨

Prompt Enhancement

Gemini 2.5 Flash analyzed and improved the original marketing description before sending it to the image generation workflow.

⚡

Automated Delivery

Generated images were automatically stored in Google Drive and linked back to the original Monday.com item.

02 — Challenge

The problem

Disconnected creative workflow

Marketing requests were managed in Monday.com, while image generation and file storage required separate tools and manual interaction.

What needed to change

The objective was to connect the request, AI processing, image generation, file storage and final delivery into a single automated workflow.

05 — AI Processing

Turning a simple request into an optimized prompt

Before generating the image, the original marketing request was processed by Gemini 2.5 Flash. The model improved and structured the prompt so that the image-generation system received clearer instructions.

01

Receive the request

Make retrieves the description and any reference images attached to the Monday.com item.

02

Enhance the prompt

Gemini 2.5 Flash analyzes the original description and transforms it into a more detailed image-generation prompt.

03

Generate the image

The enhanced prompt and available reference images are sent to the Nano Banana image-generation workflow.

06 — Automation Architecture

An asynchronous generation workflow

Because image generation does not return the final asset immediately, the solution was divided into separate automation stages. One workflow initiated the generation request, while another retrieved the generated image after processing.
